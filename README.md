# Abstrak

A simple Android client for [Audiobookshelf](https://www.audiobookshelf.org/).

## Features

- Browse and search your audiobook libraries.
- Stream audiobooks with background playback and media controls.
- Sync playback progress with your server.
- Navigate chapters, adjust playback speed, and set a sleep timer.
- Download and manage books and chapters. Offline playback is not available yet.

## Getting started

You’ll need [Android Studio](https://developer.android.com/studio) and an Audiobookshelf server.

```bash
git clone https://github.com/evoionosp/abstrak-android.git
```

Open the project in Android Studio, let Gradle sync, then run the `app` configuration on a device or emulator.
